This software, which was made using Processing.org, allows the user to interact with a responsive data-based UI that enables said user to search and filter through a database of flights as well as display a dynamic set of charts with various data points in order to visualise the data concisely. The interface supports a user-friendly interaction, giving the user the option to exhibit a map of the United States of America with an accurate, to scale, origin and destination point of a selected flight as well as the slick and simple tutorial which guides first time users through the interface. To summarize, this is a practical application of flight searching and displaying.
